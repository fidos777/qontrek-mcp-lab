## Separation Invariants

Block 2 reaffirms the following constitutional separations:

### Execution ≠ Valuation
- Execution layers perform work and generate proof
- Valuation layers interpret meaning without economic consequence
- No execution agent may determine valuation outcomes
- No valuation process may trigger execution

### Valuation ≠ Minting
- Valuation provides interpretive meaning only
- Valuation outputs MUST NOT be consumed by minting logic
- Valuation categories define type, not economic priority
- Minting requires separate constitutional authorization

### Proof ≠ Outcome ≠ Credit
- Proof establishes execution integrity
- Outcome demonstrates measurable transformation
- Credit represents verified real-world value
- Each layer maintains distinct constitutional role

### Eligibility ≠ Entitlement
- Eligibility determines readiness for consideration
- Eligibility does not grant economic rights
- Certification establishes legitimacy, not value
- Authority surfaces define trust, not pricing
